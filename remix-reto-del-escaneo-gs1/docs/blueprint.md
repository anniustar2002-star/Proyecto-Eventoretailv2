# **App Name**: El reto del escaneo GS1

## Core Features:

- Control del Temporizador: Botón de inicio/parada del temporizador con retroalimentación visual clara para controlar el tiempo del proceso de escaneo de códigos de barras.
- Registro de Participantes: Formulario de entrada para recopilar el nombre del participante antes de comenzar el desafío.
- Envío de Escaneo de Código de Barras: Integración del escáner de código de barras para registrar el tiempo cuando un participante escanea los códigos de barras de los 5 productos. Cada escaneo exitoso dará un aviso apropiado.
- Visualización de la Tabla de Posiciones: Visualización de la clasificación en tiempo real, actualizada después de que cada participante termina, mostrando el nombre y el tiempo de finalización.

## Style Guidelines:

- Color primario: GS1 Blue (#002C6C) para el encabezado y el texto principal.
- Color secundario: GS1 Dark Gray (#4D4D4F) para elementos de texto menos importantes y bordes.
- Color de acento: GS1 Orange (#FF6A13) para botones de acción clave como 'Comenzar' y 'Enviar'.
- Fondo: Blanco (#FFFFFF) para mantener un diseño limpio y legible.
- Utilice tipografía clara y legible para mostrar nombres, tiempos e instrucciones.
- Asegúrese de que la aplicación sea receptiva y se adapte a varios tamaños de pantalla de computadoras portátiles.
- Utilice iconos temáticos relacionados con GS1 y el escaneo de códigos de barras para mejorar la apariencia visual.
- Incorpore animaciones sutiles, como transiciones suaves y resaltados, para brindar retroalimentación visual y hacer que la aplicación sea más atractiva.
