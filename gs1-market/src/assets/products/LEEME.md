# Imágenes de los productos

Coloca aquí una imagen por producto, **nombrada con el número del producto** (puede llevar texto después del número):

| Archivo | Producto |
|---|---|
| `1.png` (o `1-leche.png`) | Leche |
| `2.png` | Mantequilla |
| `3.png` | Pasta |
| `4.png` | Cereal |
| `5.png` | Aceite |
| `6.png` | Lata de Maíz |
| `7.png` | Jarabe para la tos |
| `8.png` | Jabón Facial |
| `9.png` | Caja de Acetaminofén |
| `10.png` | Barra de Chocolate |

Formatos: png, jpg, webp o svg. Mejor con fondo transparente y cuadradas (p. ej. 800x800).
Si falta la imagen de un producto, la app usa un icono provisional con su nombre.
